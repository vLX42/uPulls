Install

  1. Download and unzip, then drag uPulls.app to /Applications.
  2. Bypass Gatekeeper once. The build is ad-hoc signed, not notarized. 
    $ xattr -d com.apple.quarantine /Applications/uPulls.app
    Or right-click the app → Open → Open.
  3. Connect GitHub. If the gh CLI is logged in, uPulls picks up its token by itself. Otherwise paste a personal access token in Settings.
    Classic token with repo, or a fine-grained token with Pull requests: read.
  4. Add repositories as owner/repo or by pasting a GitHub URL. Allow notifications when macOS asks.

Features

  • Every repo and PR visible at once; nothing to expand
  • Review state, CI status, author, age per PR
  • Your PRs stand out; a pill marks ones waiting on you
  • Notified on comments, change requests, approvals
  • Fireworks when your PR gets approved, tunable
  • Mute a repo for 1h, until tomorrow, or for good
  • Snooze everything while you take a break
  • Dependabot and Renovate PRs hidden by default
  • Copilot reviews and bot chatter kept quiet
  • Launch at login, one GraphQL request per minute

Requirements

  • macOS 14 (Sonoma) or later
  • Apple Silicon (M1/M2/M3/M4)
  • A GitHub account with access to the repos you track
